# 🏛️ Mapa antického Řecka

Interaktivní projekt vytvořený pro výuku dějepisu, jehož cílem je přiblížit antické Řecko moderní a přehlednou formou. Aplikace kombinuje mapu, časovou osu a informace o filozofických směrech, aby uživatelé lépe pochopili souvislosti mezi místem, časem a myšlenkami významných osobností.

Uživatel může procházet jednotlivá města, zobrazit si jejich popis, obrázky a objevit filozofy, kteří jsou s nimi spojeni. Každý filozof má vlastní profil s krátkým shrnutím jeho života a hlavních myšlenek.

Projekt je zaměřen na interaktivní učení – místo pasivního čtení si uživatel informace aktivně objevuje.
